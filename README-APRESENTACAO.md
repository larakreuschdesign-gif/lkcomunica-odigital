# 📊 Apresentação Diagnóstico EOX - Guia de Uso

## Como abrir a apresentação

### Opção 1: Abrir diretamente no seu navegador
Localize o arquivo `apresentacao-diagnostico-eox.html` na pasta do projeto e:
- **Windows**: Clique duplo no arquivo
- **Mac**: Clique duplo ou arraste para o navegador
- **Linux**: Clique duplo ou use `xdg-open apresentacao-diagnostico-eox.html`

### Opção 2: Servir localmente (em terminal/SSH)
```bash
cd /home/user/lkcomunica-odigital
python3 -m http.server 8000
```
Depois acesse: `http://localhost:8000/apresentacao-diagnostico-eox.html`

### Opção 3: Usar um servidor Node/Express
Se preferir um servidor mais robusto, pode usar `http-server`:
```bash
npm install -g http-server
http-server
```

- Visualize o progresso no topo da tela
